PATCH KATALOG UNIT BISNIS SIGAPRODUCTION

1. Backup database terlebih dahulu.
2. Ekstrak isi ZIP ke root project Laravel dan izinkan file ditimpa. Struktur folder di dalam ZIP sudah sesuai dengan Laravel (app, routes, resources/views, database/migrations, database/seeders).
3. Pastikan tidak menjalankan migrate:fresh.
4. Jalankan perintah berikut dari folder project:

   php artisan migrate
   php artisan db:seed --class=BusinessUnitSeeder
   php artisan db:seed --class=BusinessItemSeeder
   php artisan optimize:clear

PERUBAHAN:
- Music Services lama diubah menjadi Music Equipment dengan slug music-equipment. Baris lama diperbarui berdasarkan slug agar ID unit bisnis tetap dipertahankan.
- Ditambahkan katalog item pada tujuh unit bisnis.
- Setiap item memiliki halaman katalog dan tombol Pesan.
- Tombol Pesan membuka form Bookings & Orders dengan unit dan item sudah dipilih.
- Pesanan disimpan ke tabel bookings dan tampil di daftar pesanan yang sudah ada.
- Harga item yang telah diisi di katalog akan diambil dari database oleh server. Harga awal item adalah 0 karena harga resmi belum diberikan; ketika harga katalog masih 0, admin dapat mengisi harga pada form pemesanan.

CATATAN:
Daftar item yang disediakan adalah contoh awal berdasarkan jenis unit bisnis, bukan daftar stok resmi. Silakan sesuaikan nama dan deskripsi dengan layanan/produk aktual SIGAPRODUCTION.
